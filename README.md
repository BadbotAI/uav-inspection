# 仓储无人机巡检 App（高保真前端 Demo）

依据《仓储无人机巡检App-开发说明书-v1.0》实现。全部使用 mock 数据，不连真实设备；数据层经 `src/api/index.ts` 抽象，后续可替换为真实设备协议。

## 运行

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 产物在 dist/，可离线部署（无外网依赖）
```

浏览器打开后建议用开发者工具切到 390×800 移动端视口，或直接使用页面中央的手机外框。

## 演示要点

- 右侧「DEMO 控制台（不属于产品）」可跳转任意状态、触发停障/异常、切换飞行速度（1×/8×/24×）。URL 加 `?demo=0` 隐藏。
- 键盘 Esc = Android 物理返回键（执行态只最小化，永不下发飞行指令）。
- 登录：任意非空账号密码。
- 主路径：巡检 Tab「一键启动」→ 七项检查（第 7 项需人工点击确认）→ 3 秒倒计时 → 执行态（可暂停/长按返航/最小化）→ 返航 → 数据处理六阶段 → 体积成果。
- 航线详情（R-01）：航线叠加在最近一次巡检点云上，橙色高亮段 = 离堆最近航段，「最小离堆」由航线高度与堆高实时算出。
- 成果：T3（覆盖 43%）全链路标注部分覆盖；T4 为规则码垛分层计数；S-03 点击堆体卡片就地展开遮挡说明；容重在 设备 → 设置 修改后实时重算。

## 技术栈

Vite · React 18 + TypeScript · Tailwind CSS 4（token 走 CSS 变量）· three.js（裸用，单 renderer 双视口画中画）· zustand。无路由、无后端、无 localStorage（约束 C9/C10）。

## 目录

```
src/
  api/        数据层门面（页面不得直接 import mock）
  mock/       8.2 节 mock 数据（照抄，改动需同步一致性校验表）
  three/      点云生成(8.3)/航线/手写轨道控制/双视口渲染
  sim/        飞行模拟状态机驱动 + DEMO 控制台动作
  components/ 全局组件（G-01~G-05、三维视图容器等）
  screens/    L/H/R/X/S/D 全部页面
  store.ts    zustand：任务状态机 + 导航 + 返回键规则
  constants.ts 第 13 章待定项常量
```
